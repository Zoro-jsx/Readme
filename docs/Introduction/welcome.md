**Welcome to the Court Record Platform**

The Court Record Platform is a developer-first API service that provides structured, reliable access to Indian court case data spanning district courts, state high courts, and the Supreme Court of India. Our platform is built with a clean REST architecture and a consistent data model, enabling legal technology companies, compliance teams, research institutions, and litigation support services to programmatically integrate court record data into their products and workflows.

As an API-first platform, every capability available through our developer portal is equally available through the REST API itself. Whether you are building a case monitoring dashboard, automating compliance checks, or constructing a full-scale litigation management system, the Court Record Platform API provides the depth and reliability your integration requires.

**Understanding the Court Record Platform API**

The API follows REST conventions throughout. All endpoints accept standard HTTP methods, all responses are returned as JSON with a consistent envelope, and all authentication uses standard Bearer token headers. Developers familiar with any modern REST API will find the Court Record Platform API immediately approachable.

The API exposes endpoints across five primary resource areas — case search, case detail, case refresh, court structure, and billing — each documented with request schemas, response examples, and error specifications. Access to the API is metered through a credit system, allowing both subscription-based and pay-as-you-go usage patterns depending on your integration volume.

We encourage you to explore the API reference and guide sections to understand the full scope of what the platform can offer. The getting started guide will have you making live API calls within minutes.
